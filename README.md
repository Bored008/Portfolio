## ✨ Features

- **Modern & Responsive Design:** Flawless experience across all devices and screen sizes.
- **Interactive UI & Animations:** Powered by **Framer Motion** and **GSAP** for a highly engaging user experience.
- **Smooth Scrolling:** Integrated with **Lenis** for butter-smooth scroll dynamics.
- **Project Showcase:** Detailed project cards with technology tags, descriptions, and links.
- **Skills & Tech Stack:** Organized display of my technical expertise.
- **Education Timeline:** A structured journey of my academic background.
- **FAQ Section:** Quick answers to common queries.
- **Downloadable Resume:** Direct access to my latest CV.
- **Contact Section:** Easy ways to connect and collaborate.
- **Performance Optimized:** Fast load times and high SEO scores, tracked with **Vercel Analytics**.

## ⚡ Getting Started

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Bored008/Portfolio.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd Portfolio
   ```

3. **Install dependencies:**
   Using npm:
   ```bash
   npm install
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```

5. **Open in Browser:**
   Visit [http://localhost:3000](http://localhost:3000) to see the result.
